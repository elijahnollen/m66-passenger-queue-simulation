# Code

This folder contains the Jupyter notebooks used for the M66 passenger queue simulation and GA optimization project.

## Required Run Order

Run the notebooks in this order:

1. `m66_dataset_analysis.ipynb`
2. `m66_baseline_simulation.ipynb`
3. `m66_scenario_simulation.ipynb`
4. `m66_ga_optimization.ipynb`

The order matters because later notebooks use processed files generated by earlier notebooks.

```text
Dataset Analysis
      ↓
Baseline Simulation
      ↓
Scenario Simulation
      ↓
GA Optimization
```

## Working Directory

Run Jupyter from this folder so the notebooks can resolve their relative paths correctly.

From the repository root:

```powershell
cd MODESIM_Project\code
jupyter lab
```

Select the project Jupyter kernel before running the notebooks.

For complete environment setup, dependencies, project structure, input/output locations, experimental design, and reproducibility information, see the repository root `README.md`.
