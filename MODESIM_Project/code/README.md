# Code

This folder contains the four Jupyter notebooks used for the M66 passenger queue simulation and GA optimization project.

## Required Run Order

Run the notebooks in this order:

1. `m66_dataset_analysis.ipynb`
2. `m66_baseline_simulation.ipynb`
3. `m66_scenario_simulation.ipynb`
4. `m66_ga_optimization.ipynb`

Dependency flow:

```text
Dataset Analysis
      ↓
Baseline Simulation
      ↓
Scenario Simulation
      ↓
GA Optimization
```

The order matters because later notebooks use files generated by earlier notebooks.

## Notebook Roles

| Notebook | Role | Important generated dependency |
|---|---|---|
| `m66_dataset_analysis.ipynb` | Data filtering, cleaning, GTFS mapping, quality checks, descriptive analysis | Cleaned selected-stop dataset |
| `m66_baseline_simulation.ipynb` | Baseline DES, 30 replications, precision, GA/SA/PSO screening | Replication seeds, Baseline streams/results, AI-screening evidence |
| `m66_scenario_simulation.ipynb` | Baseline and three stress-test reference conditions | High-Demand streams, scenario reference results, Reduced-Service plan |
| `m66_ga_optimization.ipynb` | GA optimization and validation for all four conditions | Optimized plans, paired comparisons, validation and precision evidence |
